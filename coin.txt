To build a dynamic 3D coin with distinct front and back faces, map an array of materials to a `CylinderGeometry` using React Three Fiber and `@react-three/drei`. By combining a material array with `<RenderTexture>`, you can pass dynamic text strings and SVGs directly into the 3D material as a texture or an engraved bump map.

**Dependencies**
`npm install three @react-three/fiber @react-three/drei`

**The Dynamic Coin Component**

```jsx
import { Canvas } from '@react-three/fiber'
import { OrbitControls, RenderTexture, Text, Center } from '@react-three/drei'

export default function DynamicCoin({ archetype = "Cockroach", companyName = "Your Company" }) {
  return (
    <Canvas camera={{ position: [0, 2, 5], fov: 45 }}>
      <ambientLight intensity={0.5} />
      <directionalLight position={[10, 10, 5]} intensity={1.5} />
      
      <mesh rotation={[Math.PI / 4, 0, 0]}>
        {/* Args: [radiusTop, radiusBottom, height, radialSegments] */}
        <cylinderGeometry args={[2, 2, 0.2, 64]} />

        {/* Material 0: The Coin Edge */}
        <meshStandardMaterial attach="material-0" color="#c0c0c0" metalness={0.8} roughness={0.2} />

        {/* Material 1: The Front Face (Archetype Icon/Text) */}
        <meshStandardMaterial attach="material-1" color="#c0c0c0" metalness={0.8} roughness={0.2}>
          <RenderTexture attach="map" anisotropy={16}>
            <color attach="background" args={['#c0c0c0']} />
            <Center>
              <Text fontSize={0.6} color="#0044FF" font="/fonts/SpaceMono.ttf">
                {archetype}
              </Text>
              {/* Note: You can replace <Text> with an SVG loader here for the actual insect graphic */}
            </Center>
          </RenderTexture>
        </meshStandardMaterial>

        {/* Material 2: The Back Face (Company & egomonk) */}
        <meshStandardMaterial attach="material-2" color="#c0c0c0" metalness={0.8} roughness={0.2}>
          <RenderTexture attach="map" anisotropy={16}>
            <color attach="background" args={['#c0c0c0']} />
            <Center rotation={[0, Math.PI, 0]}> {/* Flipped to render correctly on the bottom face */}
              <Text position={[0, 0.4, 0]} fontSize={0.4} color="#000000">
                {companyName}
              </Text>
              <Text position={[0, -0.4, 0]} fontSize={0.3} color="#0044FF">
                egomonk
              </Text>
            </Center>
          </RenderTexture>
        </meshStandardMaterial>
      </mesh>

      <OrbitControls autoRotate autoRotateSpeed={2} />
    </Canvas>
  )
}

```

**Core Mechanics**

* **The Material Array:** A `CylinderGeometry` automatically accepts exactly three materials mapped to `[side, top, bottom]`. Using `attach="material-0"`, `attach="material-1"`, and `attach="material-2"` binds them to the correct faces.
* **On-the-Fly Texturing:** `<RenderTexture>` creates an isolated React rendering tree that is converted into a 2D image map. This allows you to pass React props (like the user's company name) straight into the 3D texture without pre-rendering image files.
* **Back-Face Flipping:** Because the bottom of a 3D cylinder faces downwards, standard textures will appear mirrored. Wrapping the back-face content in a `<Center 0]} Math.PI, rotation="{[0,">` flips the text so it is legible when the coin rotates.
* **The Engraved Look:** To make the text look physically stamped into the metal rather than printed on it, change `attach="map"` to `attach="bumpMap"` inside the `RenderTexture`, and set `bumpScale={-0.02}` on the `meshStandardMaterial`. Make the background of the RenderTexture white, and the text black. The 3D lighting engine will treat the black text as physical indentations in the coin.
