**System Role & Architecture**
Build an interactive Next.js WebGL application using React Three Fiber, Framer Motion, and Tailwind CSS. The app is a spatial narrative quiz and 3D token generator called "The Instinct Series."

* **Aesthetic:** "Techno-Romanticism." A fusion of retro-industrial hardware and high-end holographic artifacts.

* **Typography:** Use a strict monospace font (e.g., Space Mono or JetBrains Mono) for UI elements, tags, and buttons to mimic an LED dot-matrix screen. Use a sharp, high-contrast serif font for the main narrative text and questions.
* **FX:** Overlay the entire background with a subtle, animated CSS scanline or LED dot-matrix grid shader.

**Core User Flow & Components**

**1. The Scenario Terminal (Quiz UI)**

* Do not use standard radio buttons or form fields. Display questions as centered, terminal-style prompts or physical-looking digital "paper slips."

* Use Framer Motion to animate the transition between questions with a slow, cinematic fade.

* When the quiz completes, aggregate the score to determine one of four archetypes: Cockroach (Resilience), Bull (Momentum), Unicorn (Hyper-Growth), or Chameleon (Reinvention).

* Render a 3D metallic coin. Include an interactive shader that reacts to the mouse: the coin should initially render as a glowing, low-res LED dot-matrix hologram, then seamlessly transition into a highly realistic, silver-and-iridescent-blue metallic texture.

**3. The Founder Passport (Output)**

* Below the 3D coin, render a clean, minimalist "Instinct Card."

**Behavioral Constraints**
Ensure the WebGL canvas is highly optimized. Do not use external image assets for the UI; rely on CSS gradients, SVG line art, and programmatic shaders for the dot-matrix and holographic effects.
